# The Invention, Not the Inventor: Patent Renewal by Emerging-Market Firms

Short paper (draft). LaTeX source, compiled with pdfLaTeX + BibTeX (Overleaf default).

- `main.tex`: preamble, title, abstract; includes the sections.
- `sections/`: one file per section and the appendix.
- `references.bib`: bibliography (entries still to be checked against published versions).

Numbers in the tables are transcribed from the analysis notes of the companion project `em-patent-value`
(`notes/01_first_results.md`); each table names its source script in a comment.
